# Production-Grade AWS Monitoring & Observability Platform

This is a hands-on DevOps portfolio project focused on building a production-style monitoring and observability platform on AWS.

The project will deploy a small multi-tier web application and monitor the infrastructure, containers, application, database, logs, availability, and alerts.

## Planned Stack

- AWS EC2
- Application Load Balancer
- React
- Node.js
- MySQL
- Docker
- Prometheus
- Grafana
- Loki
- Grafana Alloy
- Node Exporter
- cAdvisor
- mysqld_exporter
- Blackbox Exporter
- Alertmanager
- Terraform
- Ansible

## Main Goals

- Monitor EC2 server health
- Monitor Docker containers
- Collect Node.js application metrics
- Monitor MySQL
- Check application availability
- Centralize logs
- Create useful Grafana dashboards
- Configure meaningful alerts
- Test controlled failure scenarios
- Reproduce the infrastructure with Terraform and Ansible

## Current Status

Project foundation and architecture planning are in progress.

The infrastructure will be built in AWS `ap-south-1` with cost control as an important design requirement.
